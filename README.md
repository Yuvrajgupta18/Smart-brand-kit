# Smart Brand Kit – Adobe Express Add-on

Enterprise-focused Adobe Express add-on that transforms static brand guidelines into enforceable compliance rules, enabling organizations to validate creative assets against predefined branding standards and maintain brand consistency at scale.

---

## Overview

Organizations invest significant effort in creating brand guidelines covering logo usage, typography, color palettes, layouts, and visual identity standards. However, these guidelines are often distributed as static documents, making compliance difficult to enforce consistently across teams.

Smart Brand Kit bridges this gap by converting branding standards into enforceable digital rules that automatically evaluate creative assets, identify violations, and support governance workflows within Adobe Express.

The platform enables marketing, design, and brand teams to streamline approval processes, reduce branding inconsistencies, and maintain a unified brand identity across all creative assets.

---

## Problem Statement

Large organizations frequently encounter challenges such as:

* Inconsistent logo usage across assets
* Incorrect brand color implementation
* Non-standard typography usage
* Manual compliance review processes
* Delayed approval cycles
* Difficulty enforcing branding standards across distributed teams

Traditional brand guidelines are often stored as PDFs or documentation, making them difficult to operationalize and enforce in day-to-day creative workflows.

---

## Solution

Smart Brand Kit converts static branding guidelines into rule-based validation systems that automatically assess creative assets against predefined company standards.

The platform provides:

* Automated compliance validation
* Real-time violation detection
* Centralized brand rule management
* Governance-focused review workflows
* Compliance reporting and analytics

This helps organizations maintain brand consistency while significantly reducing manual review effort.

## Installation

### Clone Repository

```bash
git clone https://github.com/TanmayJindal1205/adobe-smart-brand-kit.git
```

### Navigate to Project

```bash
cd adobe-smart-brand-kit
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
